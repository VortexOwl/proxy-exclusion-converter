# Proxy exclusion converter
Веб-приложение для извлечения списков исключений прокси из Markdown-файлов.

Программа ищет строки, начинающиеся с выбранного маркера, объединяет их содержимое и возвращает готовый список исключений прокси. Результат можно показать в браузере, сохранить в текстовый файл или записать в профиль браузера Floorp.

Возможности
* загрузка Markdown-файла через веб-форму;
* выбор маркера строк с исключениями;
* отображение результата в браузере;
* сохранение результата в файл .txt;
* запись списка исключений в профиль Floorp;
* удаление ранее добавленной настройки прокси из профиля браузера;
* выбор профиля браузера через страницу конфигурации;
* автоматическая очистка временных файлов при остановке приложения

## Как использовать программу

1. Скачайте и распакуйте загруженный ZIP-архив в отдельную папку.
2. Запустите файл `proxy-exclusion-converter.exe`.
   После запуска откроется окно терминала, а в браузере по умолчанию автоматически запустится веб-интерфейс по адресу `localhost:8000/converter`.
3. Работайте через браузер. Для остановки сервера используйте кнопку в интерфейсе **Остановить сервер приложения**, endpoint `/shutdown` или сочетание клавиш `Ctrl+C` в терминале.
4. В поле Маркер укажите маркер строк с исключениями. По умолчанию используется `*`.
5. Выберите исходный Markdown-файл.
6. Укажите, нужно ли сохранить результат в файл.
7. Нажмите **Конвертация**.
8. Просмотрите результат или скачайте созданный .txt-файл.

## Формат исходного файла
Программа обрабатывает только строки, которые начинаются с указанного маркера. Первый символ-маркер удаляется, а оставшееся содержимое добавляется в результат.

Например, для маркера `*` подойдёт такой файл:

```md
# Базовые
* 127.0.0.1, localhost, .example.com,

---

# Браузеры
## Firefox
* accounts.firefox.com, mozilla.org,

---

# Поисковые системы
## Google
* .google.com, .gstatic.com,

## Yandex
* .yastatic.net, .yclients.com, .yandex.com, .yandex.net, .naydex.net, storage.yandexcloud.net,

---

# Искусственный интеллект
## DeepSeek
* .deepseek.com

---
```
Заголовки Markdown и разделители --- игнорируются, поскольку не начинаются с маркера `*`.

## Результат будет иметь вид:

```
 127.0.0.1, localhost, .example.com, accounts.firefox.com, mozilla.org, .google.com, .gstatic.com, .yastatic.net, .yclients.com, .yandex.com, .yandex.net, .naydex.net, storage.yandexcloud.net, .deepseek.com
```

## Настройка профиля Floorp
Приложение записывает список исключений прокси в файл:

```
<профиль браузера>/user.js
```
В файл добавляется настройка:
```
user_pref("network.proxy.no_proxies_on", "<список исключений>");
```
Если настройка с таким именем уже существует, она удаляется перед добавлением нового значения.
Чтобы удалить добавленную настройку, используйте кнопку отката конфигурации браузера. 
После изменения файла необходимо перезапустить Floorp, чтобы браузер применил настройки.

## Выбор профиля
Откройте страницу:
```
http://localhost:8000/update-config
```
На странице конфигурации можно указать путь к профилю браузера. Если выбрать использование профиля по умолчанию, приложение перестанет использовать пользовательский путь и снова будет искать профиль автоматически.


## HTTP-endpoints

| Метод | Путь | Назначение | 
|---|---|---| 
| `GET` | `/` | Перенаправление на /converter | 
| `GET` | `/converter` | Отображение формы конвертации | 
| `POST` | `/converter` | Конвертация загруженного файла | 
| `POST` | `/set-proxy-exception/firefox` | Обновление списка исключений в профиле браузера | 
| `POST` | `/set-proxy-exception/rollback-browser-config` | Удаление настройки исключений из профиля браузера | 
| `GET` | `/update-config` | Отображение формы конфигурации | 
| `POST` | `/update-config` | Изменение пути к профилю браузера | 
| `GET` | `/shutdown` | Остановка веб-сервера | 
| `GET` | `/docs` | Интерактивная документация FastAPI |

В зависимости от заголовка `Accept` endpoint-ы возвращают HTML-страницу или JSON-ответ.

## Завершение работы
При завершении приложения выполняется очистка директории временных файлов. Сервер можно остановить из веб-интерфейса кнопкой **Остановить сервер приложения**, через `/shutdown` или сочетанием клавиш `Ctrl+C`.
